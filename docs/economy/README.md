# Economy

Current economic contracts implemented by Antares and composed in Vega. These web systems work without Minecraft; physical geography, buildings and goods are future integration work.

| Reference                                                  | Responsibility                                                                                        |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| [Monetary system](monetary.md)                             | Central banks, currencies, monetary policies, wallets, treasury and immutable double-entry accounting |
| [Companies](companies.md)                                  | Registration, corporate Governance, shares, subsidiaries, branches and official finance               |
| [Currency exchange](currency-exchange.md)                  | Bilateral bank settlement and finite reserved offers for players                                      |
| [Taxation](taxation.md)                                    | Institutions, national laws, jurisdictions, tax calculation and atomic settlement                     |
| [Tax settings and corporate regimes](taxation-settings.md) | Liability, allowances, beneficiaries, company-specific rules and fractional obligations               |
| [Diplomacy](../states/diplomacy.md)                        | Independent state ratification of bilateral tax treaties                                              |

Authority comes from published [Governance](../states/governance.md), with the shared [Voting](../platform/voting.md) service where required. Registration policies, company charters and state decisions have distinct scopes. Monetary journals retain exact amounts and immutable history. See [verification evidence](../verification/README.md) for completed runs and [implementation history](../history/README.md) for release records.
