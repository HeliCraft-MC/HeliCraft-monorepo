# Economy

Действующие экономические контракты Антареса и их интерфейсы в Веге. Эти веб-системы работают без Minecraft; физическую географию, здания и товары ещё предстоит интегрировать.

| Справочник                                                          | Ответственность                                                                                |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [Денежная система](monetary_RU.md)                                  | ЦБ, валюты, денежные политики, кошельки, казна и неизменяемая двойная запись                   |
| [Компании](companies_RU.md)                                         | Регистрация, корпоративное управление, акции, дочерние компании, филиалы и официальные финансы |
| [Обмен валют](currency-exchange_RU.md)                              | Двусторонние сделки банков и конечные обеспеченные предложения игрокам                         |
| [Налоги](taxation_RU.md)                                            | Учреждения, национальные законы, юрисдикции, расчёт налогов и атомарное исполнение             |
| [Настройки налогов и корпоративные режимы](taxation-settings_RU.md) | Плательщик, необлагаемая часть, получатели, адресные режимы компаний и дробные обязательства   |
| [Дипломатия](../states/diplomacy_RU.md)                             | Независимая ратификация двусторонних налоговых договоров государствами                         |

Полномочия задаёт опубликованный [Governance](../states/governance.md), при необходимости используется общий [Voting](../platform/voting.md). Политика регистрации, устав компании и государственные решения имеют разную область действия. Денежные журналы сохраняют точные суммы и неизменяемую историю. Выполненные прогоны — в [Verification](../verification/README_RU.md), журналы выпусков — в [History](../history/README_RU.md).
