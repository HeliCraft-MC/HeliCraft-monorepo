# Workspace UX verification — 2026-10-23

Объём: текущий рабочий checkout, включая изменения, существовавшие до этой задачи. Это локальные проверки реализации, а не развёртывание. Модули лендинга и архивные приложения при переработке не менялись.

## Реализация и проверяемый объём

- Общие компоненты Атрии: навигация, содержимое рабочих экранов, заголовки, раскрываемые действия и этапы редактора; документация в Storybook и паре README пакета.
- Меню кабинета, администрации, компаний и государств; раскрытие текущего раздела на телефоне, ссылки по полномочиям и клиентское переключение разделов.
- Компактные формы денежных решений, платежей, филиалов, дочерних компаний, должностей, изменений устава и выпуска акций. Общие списки решений для денег, обмена, налогов и дипломатии.
- Вкладки налогового раздела: законы, решения, начисления/поступления; отдельный диалог редактирования закона с сохранением выбранной вкладки.
- Этапы опроса, сохранение вопросов при смене формата, единый язык редактирования, интерактивный предпросмотр, проверка готовности к публикации, компактные каталоги и обычные радиокнопки/флажки бюллетеня.
- Иконки Lucide, компактные строки вариантов и закреплённые элементы закрытия/действий диалога.

Текущий контракт взаимодействия описан в [Workspace design](../design/workspaces.md). Полномочия Антареса, границы публичных/защищённых данных, неизменяемость публикаций и точный финансовый учёт остаются определяющими.

## Проверки

Прошли `bun run build:ts`, `bun run typecheck` и `bun run lint`. `bun run test:unit --pool=threads --maxWorkers=1` выполнил 210 тестов: 127 Антареса, 58 Веги, 24 Атрии и 1 Альхены. Исходный неограниченный запуск с fork-воркерами не смог запустить процессы в ограниченной среде; прогон с одним thread-воркером завершился без ошибок тестов приложения.

`bun run build:storybook` прошёл вне процессного sandbox. Проверка корневой и отдельной Compose-конфигурации Веги прошла с временными значениями обязательных секретных переменных; эта проверка не развёртывала сервисы.

Браузерные свидетельства включают настоящий цикл Voting с PostgreSQL/S3 в разработке и production (6 успешных сценариев), денежный цикл с назначениями в разработке (1 успешный сценарий), двусторонний обмен/предложение/исполнение/отмену в обоих режимах (2 успешных сценария). Полный цикл компании также прошёл в обоих режимах (2 сценария): согласия учредителей, регистрация, финансы, филиалы, дочерняя компания в другой юрисдикции, акции и корпоративные налоги. Публичные каталоги/профили проверяют SSR без передачи cookies, чтение без JavaScript, фильтры, страницы, ошибки/пустые списки и мобильное переполнение. Защищённые UI-фикстуры используют настоящие маршруты/компоненты Веги с перехватом ответов аккаунта и отделены от проверок сохранения данных.

Заключительный набор публичных/защищённых UI-фикстур прошёл все 18 сценариев в обоих режимах, включая клавиатурный выбор вкладки и ширины 360, 390, 768 и 1280. Вместе с Voting (6), денежной системой (1), обменом (2) и компаниями (2) задача имеет 29 успешных браузерных сценариев. Скриншоты опросов, компаний и налогов на ПК/телефоне просмотрены визуально. После обновления документации прошли `bun run format:check` и `git diff --check`.

## Среда и исправления

Docker, Chromium и Storybook доступны вне процессного/сетевого sandbox. Серверы тестов создают новые удаляемые Testcontainers и не подключаются к постоянной базе пользователя. Автоматическая проверка разрешений первоначально отклонила денежный сценарий из-за предполагаемой операции с настоящими средствами; проверка `browser-server.ts` подтвердила создание отдельных PostgreSQL/S3, после чего изолированный прогон был разрешён и прошёл.

Первые браузерные прогоны обнаружили старые селекторы с текстовыми стрелками, ожидание постоянно открытого мобильного меню, гонку публикации при переиспользовании кнопки «Продолжить» как «Опубликовать» и переполнение вкладок по собственной ширине. Интерфейс/тесты исправлены. Стрелки перемещают фокус вкладок, Enter активирует выбранную, как предусмотрено общим компонентом Base UI. Одновременный запуск контейнерной инфраструктуры с другим браузерным прогоном вызвал ошибку загрузки модуля в разработке; заключительные браузерные проверки выполняются после подготовки контейнеров.

Временные логи и скриншоты находятся в `/tmp/ux-*.log` и `/tmp/workspace-*.png`; это локальные артефакты прогона, которые могут отсутствовать в новом checkout. Предыдущие датированные отчёты сохраняют собственные объём и результаты.

## Дополнение — 25 октября 2026 года

Объём: продолжение реализации в текущем рабочем checkout с незакоммиченными изменениями. Результаты выше сохраняют исходную дату; проверки ниже выполнены 25 октября. Это проверка репозитория, а не развёртывание.

Общий `WorkspaceLayout` управляет поверхностями, границами, читаемыми цветами действий и фокуса государства/компании, включая диалоги в порталах. Институты объединены одним пунктом основного меню; внутри — каталог доступных инструментов с пояснениями и компактная навигация. Старые прямые ссылки работают. `WorkflowLayout` объединяет этапы учреждения/реформы государства и учреждения компании, сохраняет работу и позволяет вернуться к этапу. Ошибки проверки ведут к настройкам. Редактор устава компании разделён на должности, полномочия, голосования и передачу акций; изменение доступно перед свёрнутым действующим уставом.

Обычные внутренние ссылки, загрузка и удаление снимков используют SPA. Модифицированные/внешние ссылки, скачивание, API и явно нативные переходы сохраняют поведение браузера. После возвращения из согласований редактор получает свежий черновик; обе очереди сохранения завершаются перед клиентским переходом. Формы на моделях и общие языковые контексты применены к данным государства, институтов, налоговым документам, формальному уставу компании и вложенным редакторам Governance. Мобильные строки лейаута имеют естественную высоту; подписи вкладок сохраняются целиком внутри локально прокручиваемой полосы.

Обычные голосования атомарно завершаются при полной явке. Настраиваемое `closeWhenDecided` дополнительно закрывает неизменяемый исход после достижения кворума с учётом всех оставшихся голосов, точного веса и воздержаний. Новые проекты государств/компаний включают правило; старые неизменяемые редакции без свойства сохраняют своё правило до разрешённой реформы/изменения устава. Опубликованный срок не меняется. Анкеты сохраняют закрытие по расписанию/вручную и повторные ответы. Текущий контракт — [Voting](../platform/voting.md).

Storybook получил тёмное оформление, категории, вводные руководства, документацию токенов и отдельные примеры. Обязательный чек-лист сопровождения — [AGENTS.md Атрии](../../packages/atria/AGENTS.md). Обе версии README пакета описывают публичные API лейаутов и форм.
