GDD описывает целевые игровые системы. Справочники описывают реализованный веб-объём и явно оформленные уточнения конкретных версий. Будущий замысел не доказывает готовность механики в Minecraft. Расхождения нужно обозначать или оформлять как явные уточнения; предложение нельзя молча объявлять реализацией.

Корневая папка `archive/` содержит прежние продукты и документацию. Это справочный материал только для чтения, вне текущего ведения документации. Существующие английские и русские пары ссылаются друг на друга; непарные справочники сохраняют свой язык. Обзор для администрации намеренно написан на русском для своей аудитории.
