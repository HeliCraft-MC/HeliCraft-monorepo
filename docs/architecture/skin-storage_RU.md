# Skin storage and rendering

Только Антарес обращается к приватному S3. Версии скина имеют неизменяемые ключи skins/<UUID>/<версия>/skin.png и avatar.png; клиент получает HTTP URL по UUID. Проверяются сигнатура PNG, размер до 2 МиБ, 64×64/64×32, один кадр и ограничение декодированных пикселей. Legacy допускает только CLASSIC; выход всегда нормализованный 64×64.

Legacy-конечности зеркалируются по UV, а не растягиваются. Аватар складывает лицо 8×8 и внешний слой с корректной прозрачностью до увеличения nearest-neighbor до 128×128. Это отдельное изображение головы.

Оба объекта записываются и читаются до переключения указателя в БД. При отказе S3 старый скин остаётся активным. Сброс очищает указатель, сохраняя версии; удаление осиротевших объектов — эксплуатационная задача. Без кастомного скина выдаётся оригинальная текстура исследователя, обработанная тем же конвейером. 3D-просмотр в Веге загружается лениво и показывает PNG при отсутствии WebGL. Ригель позднее сможет получить данные через REST.
