# Spatial architecture

Реализовано в репозитории, без утверждения о production deployment. [Территориальный workflow](../states/territories_RU.md) описывает пользовательскую процедуру; [датированный отчёт](../verification/territories-2026-10-25_RU.md) — реальные проверки и отдельную ручную приёмку.

## Ответственность и координаты

Антарес/PostGIS хранит юридические территории государств. squaremap рендерит настоящую поверхность Minecraft и не владеет территориальными сведениями. Вега объединяет тайлы и политические слои; Денеб определяет физическую юрисдикцию по проверенным локальным снимкам JTS. Private claims, защита блоков, PvP enforcement, геология, здания и дипломатическая передача земли не входят в V1.

Геометрия — плоские Polygon/MultiPolygon с holes, единица измерения — блок, координаты GeoJSON — `[X, Z]`. PostgreSQL geometry использует SRID 0 (локальные декартовы координаты), а не geography или EPSG:4326. Диапазон ±29 999 984; кольца замкнуты, площадь положительная. Автоматическое исправление не должно заполнять holes. PostGIS проверяет топологию, объём, количество вершин, площадь и наложение положительной площади; общий край допустим. Юрисдикция определяется строгим внутренним содержанием: точки на внешних границах, общих краях и границах holes считаются Wilderness одинаково в PostGIS и JTS. Высота не влияет на юрисдикцию.

Мир имеет неизменяемый logical ID, backend instance, Paper world UUID, dimension и статус. Геометрия применяется только при совпадении Paper UUID; пересозданный мир с прежним именем является другим миром. V1 разрешает редактирование только явно зарегистрированных активных Overworld. Nether и End остаются общими пространствами. Конфигурация карты явно задаёт world key squaremap и правила координат/масштаба после исследования зафиксированного renderer.

## Automatic primary world registration

Денеб передаёт `registerOverworld: true` с ограниченным списком загруженных миров в `POST /api/v1/internal/minecraft/spatial/worlds` при существующей асинхронной синхронизации каждые пять секунд. Для старых/читающих клиентов флаг по умолчанию false. Регистрация доступна только scoped DENEB; Антарес берёт backend ID из сервисной identity, а не тела запроса. Допускается один точный `minecraft:overworld`; повторные UUID и несколько основных Overworld отклоняются до изменения данных. Nether/End/custom keys автоматически не регистрируются.

Антарес сериализует обнаружение по backend. Совпадающий Paper UUID/dimension повторно использует неизменяемую регистрацию и настройки карты. Неизвестный UUID получает отдельный logical key и локализованное название, ключ squaremap `minecraft_overworld`, native zoom 3 и extra zoom 2. Прежняя активная привязка того же backend/tile key атомарно выводится из эксплуатации перед созданием новой. Её геометрия, черновики и история сохраняются и не копируются. Выведенные UUID не возвращаются в работу: старый процесс backend не может занять текущую привязку. Обнаружение управляет только физическим жизненным циклом и не публикует территорию/не выдаёт полномочия Governance.

Миграция `0049_spatial_world_discovery.sql` добавляет append-only `spatial_world_events` для регистрации/вывода с идентификатором сервиса, без выдуманного аккаунта администратора/игрока. Существующие территориальные ревизии и файлы пользовательского мира не меняются. Сбой запуска/API повторяется обычной синхронизацией; сетевых запросов в movement path нет. Админка показывает подключённые миры и отдельно объяснённую ручную форму. [Инструкция оператору](../states/territories_RU.md#world-connection).

## Юридические изменения и конкурентность

Существующее ACTIVE-государство может не иметь территории; дата основания, исторические решения и случайные начальные полигоны не изменяются. Версионируемый draft закрепляет state, world и базовую действующую территориальную ревизию. Сохранение использует optimistic concurrency. Отправка фиксирует геометрию, обоснование и hash в неизменяемом предложении.

Переиспользуются существующие state directives, подписи должностей, закрепление ревизий и общий Voting через уже типизированное действие Governance `CHANGE_TERRITORY`. Хранилище/API с историческим названием monetary directives уже обслуживает налоги, дипломатию, компании и FX. Новый движок полномочий и отдельные территориальные ballots не создаются. Отсутствующая policy запрещает отправку; государство добавляет её обычной реформой Governance. Presets и названия должностей не дают новых полномочий.

Успешная государственная процедура передаёт неизменяемую заявку администрации и не активирует геометрию. Администратор с обязательным обоснованием утверждает или отклоняет точную отправленную геометрию. Перед публикацией повторно проверяются ACTIVE-статус, неизменность Governance revision, непрерывные действующие должностные полномочия, закрытые успешные голосования, базовая территория и актуальные конфликты. Администрация не редактирует согласованный polygon. Утверждение атомарно добавляет территориальную ревизию/event, меняет active pointer и увеличивает версию снимка мира. Повтор идентичной команды идемпотентен; конфликтующее использование ключа отклоняется.

Публикации сериализуются по миру транзакционной блокировкой PostgreSQL; SQL защищает действующую геометрию и неизменяемую историю. Это предотвращает конкурентные пересечения, сохраняя общие края и независимость миров. Сохраняются история, обоснования и юридические доказательства. Spatial events отделены от редакционного контента и приватных событий Minecraft-сессий.

## Карта и игровой runtime

Leaflet загружается лениво только в браузере и использует плоскую CRS с совместимой со squaremap проекцией. Web Mercator и iframe не используются. Тайлы 512px используют `[lat,lng]=[-Z/2^maxZoom,X/2^maxZoom]`; обратное преобразование сохраняет отрицательные координаты. Геометрия публичной карты загружается по видимому bounding box, каталог SSR не содержит геометрии. Поддерживаемая библиотека редактирования обеспечивает polygons, компоненты, holes, вершины и undo/redo. Atria предоставляет общие controls, Вега — территориальный процесс. Публичный SSR содержит metadata из site branding, описания миров и ссылки на государства без cookies, private drafts и service credentials. Антарес повторно проверяет полномочия редактора и администрации. Выдача тайлов разрешает только зарегистрированные миры и ограниченные числовые координаты; произвольные URL/пути, пересылка cookies, player files и live markers запрещены.

Денеб асинхронно опрашивает версии через scoped DENEB Minecraft API, при изменении версии или integrity получает полный ограниченный snapshot, вне main thread проверяет схему, identity, integrity и геометрию, строит JTS STRtree и атомарно заменяет целый неизменяемый снимок. Периодическая reconciliation восстанавливается после пропущенных обновлений и потери API. В movement/teleport/join hot path нет HTTP и БД. Bukkit/player access и Adventure notifications выполняются на main thread. Login, teleport, world change, vehicles и неподвижные игроки после замены снимка используют один evaluator. Debounce убирает спам у границы; `/heli whereami` показывает физическую юрисдикцию независимо от гражданства, версия доступна с debug permission.

При недоступности пространственного API сохраняется последний проверенный снимок с явной диагностикой устаревания либо неизвестная юрисдикция до первой загрузки. Новое состояние не выдумывается, main thread не блокируется. Существующий fail-closed admission сохраняет контракт Minecraft Auth; новая функция его не ослабляет. Язык следует существующим настройкам; официальные названия используют fallback English → остальные поддерживаемые языки.

## Snapshot, limits and migrations

Scoped DENEB endpoints связывают service actor с backend и настоящим Paper UUID. Канонический UTF-8 core снимка имеет schema version 1 и SHA-256 integrity; envelope проверяется до построения геометрии и JTS index. Ссылка атомарно заменяется по миру. Polling сравнивает integrity и целочисленную версию, поэтому официальные названия/цвета обновляются без перезаписи юридической геометрии. HTTP в движении нет. Через 30 секунд без проверки прежний снимок явно помечается устаревшим; до первой загрузки юрисдикция неизвестна. Retired bindings удаляются. Локального источника полномочий нет.

`0045_sour_baron_strucker.sql` создаёт spatial schema. Проверенная `0046_spatial_integrity.sql` задаёт world locks, неизменяемость revision/review/event, соответствие state/world pointer, отложенную проверку полноты публикации и замороженные переводы обоснования, включая добавление отсутствующего языка после sealing. `0047_minecraft_approval_locale.sql` сохраняет язык сайта только после успешного browser approval конкретного соединения. Денеб использует проверенный язык, затем client locale, затем English. Язык не меняет identity и полномочия admission.

Лимиты и REST описаны в [Territories](../states/territories_RU.md). Код: `apps/antares/src/modules/spatial`, `apps/vega/src/spatial`, `FlatMap` Атриа и `SpatialEngine`/`SpatialSnapshot`/`TerritorialRuntime` Денеба. Общий PostGIS/JTS fixture фиксирует семантику границ, holes, MultiPolygon, узких областей и крайних координат. [Руководство разработки](../development/minecraft-plugins_RU.md) описывает pins артефактов, безопасные тайлы и миграции/renderer только в disposable-среде.
