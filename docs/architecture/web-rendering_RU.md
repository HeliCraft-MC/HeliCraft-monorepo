# Web rendering

Вега использует TanStack Start, Vite и React 19; каждый серверный запрос получает собственные router/query cache. Публичные страницы сначала приходят как HTML, затем гидратируются. Серверные загрузчики обращаются к Антаресу через Альхену без cookies. Черновики и личные данные не попадают в публичный HTML. `/app` и `/admin` работают в браузере с проверкой серверной сессии; вход и регистрация имеют noindex.

В production Bun запускает `dist/server/server.js`, раздаёт `dist/client` и проксирует `/api`. Для каждого HTML создаётся случайный CSP nonce, одинаковый в заголовке и скриптах Start. HTML/API используют no-store, хешированные ресурсы — immutable. Canonical, OG, Twitter и JSON-LD используют SITE_ORIGIN и реальные данные публикаций. Robots и sitemap получают список опубликованных документов из Антареса.

Workbox запускается отдельным шагом после Vite. Service worker сохраняет только JS, CSS, шрифты и иконки; HTML, API, кабинет и админка не кэшируются. Офлайн-доступ к аккаунту не реализован. Для HTTPS обязательны SECURE_COOKIES=true; SITE_ORIGIN должен точно совпадать с адресом браузера. Playwright проверяет dev и собранный SSR с временными PostgreSQL/S3.

Корневой загрузчик получает публичную навигацию без cookies: настроенные внешние ссылки и опубликованные CMS-страницы присутствуют в HTML footer. При ошибке загрузки коллекции ссылок остаются пустыми.
