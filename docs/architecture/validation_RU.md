Проверены регистрация, HttpOnly-cookie, CLI первого OWNER и повторный вызов, приватный черновик, публикация без пересборки, загрузка/сброс скина и S3-аватар, смена пароля с отзывом старой сессии, robots/sitemap, SSR CMS rules и HTTP 301 /pages/rules → /rules без дубля в sitemap. Адаптивность проверена на 360/390/768/1024/1440; desktop/mobile screenshots просмотрены визуально.

Основной .env/DATABASE_URL не настроен. Миграции применялись к настоящим временным БД helicraft; неизвестная пользовательская/production БД не затрагивалась. Для целевого запуска задайте окружение и выполните db:migrate либо migration service Compose. Все обязательные инструменты доступны. SQL проверяется вручную и применением, поскольку oxfmt его не поддерживает. Временный Compose остановлен без удаления volumes; существующие пользовательские сервисы, Java authentication и EULA сохранены.

Ограничения: rate limits живут в одном процессе; для реплик нужен общий store. Очистка истёкших сессий и неиспользуемых S3-версий не запланирована автоматически. Email/OAuth/recovery, игровая identity-интеграция, World Engine и игровые институты — следующие этапы. Ригель интегрируется только через проверенную схему подтверждения/связывания постоянного UUID с сохранением стандартной аутентификации до её готовности.

## Gallery and photographic home — 2026-10-11

Новая главная, домен галереи, generated SDK, отдельные папки компонентов и публичные routes проходят `generate`, `build:ts`, `typecheck`, строгий `lint`, `format:check`, `test:unit` (33 теста) и сборку Storybook. Корневой и затронутые Compose Vega/Antares валидны. После появления Docker production web images пересобраны и существующий HeliCraft deployment обновлён; PostgreSQL, S3, Антарес и Вега здоровы. Minecraft-сервисы не запускались, EULA не принималась.

Отдельный публичный Playwright-набор проходит восемь dev/production сценариев с исключительно тестовыми gallery fixtures: порог hero при 0/5/6 снимках, ошибка API, отсутствие передачи cookies, SSR списка/detail, 404, обычная pagination, навигация без JavaScript, mobile menu/Escape, overflow на ширинах 360–1440px и hydration. Desktop/mobile full-page и viewport screenshots сохранены в `apps/vega/test-results/gallery-public/` и визуально проверены. Fixtures показывают публичный интерфейс, не реальные записи игроков.

Все 19 интеграционных тестов в шести файлах проходят с временными PostgreSQL/PostGIS и private S3. Для галереи проверены авторизованная загрузка, отклонение неверного файла и анонимной загрузки, публичная выдача изображения, права владельца, отказ S3 без новой записи в БД, сохранение UUID автора после переименования и 404 после удаления. Миграция 0003 применяется и к чистым тестовым БД, и к `helicraft` существующего тестового deployment; зарегистрированы все четыре миграции, таблица `gallery_images` существует. Готовность deployment, публичный gallery API и SSR главной/галереи возвращают HTTP 200. Существующие volumes БД и хранилища сохранены; сброс данных не потребовался.

Полный авторизованный Playwright-набор проходит 11 development/production тестов; один development-тест production service worker ожидаемо пропущен. Проверены загрузка снимка, гостевой SSR и удаление владельцем, а также identity, скины, публикация CMS, администрация, аудит и отсутствие кеширования приватных ответов. Тест галереи учитывает обычный query `page=1` и проверяет 404 удалённого снимка; административный тест ждёт обновления формы ролей перед изменением статуса. Браузерные наборы и генерацию исходников следует запускать последовательно: их dev servers используют общие кеш Vite и generated files.

Дополнительный smoke test через фактический Docker deployment на `http://localhost:8080` проходит регистрацию, авторизованную загрузку снимка, публичное получение WebP из S3, гостевой SSR detail и удаление владельцем с последующим 404 для detail/image. Разрешённый Origin deployment согласован с портом 8080. Проверка создаёт тестовый аккаунт и мягко удалённый снимок; существующие записи не удалялись.
