# Gallery

Галерея — отдельный домен Antares, независимый от CMS, игровых событий и скинов. Vega использует generated Alhena через same-origin HTTP API; только Antares обращается к PostgreSQL и private S3. Миграция `0003_harsh_goliath.sql` создаёт `gallery_images`. Стабильные UUID снимков и неизменяемые UUID аккаунтов определяют записи и владельцев. Изменяемые имена авторов/игроков берутся из identity при чтении.

`GET /api/v1/public/gallery` использует существующие page/pageSize и возвращает ограниченную страницу с общим публичным количеством в детерминированном порядке createdAt/id. `GET /api/v1/public/gallery/{id}` возвращает публичные метаданные. Запись содержит название, plain-text описание, обязательный доступный alt, optional место, optional целочисленные x/y/z с измерением, UUID участников, размеры нормализованного изображения и время создания/публикации. Storage keys не выдаются. Загрузка сразу публикует снимок; минимальный домен не содержит draft/private upload или moderation workflow. Удалённые записи исключены из публичных чтений, hero и sitemap.

`POST /api/v1/account/gallery` принимает multipart file и JSON-строку `metadata`, проверяет существующую сессию и использует UUID principal как владельца. Действует текущая проверка browser origin/CSRF. Лимит файла 10 МиБ, лимит декодирования 24 млн пикселей, whitelist статичных PNG/JPEG/WebP и строгий decoder исключают подмену формата, анимацию и oversized decode. Sharp ориентирует, декодирует и выдаёт WebP без исходных метаданных: display до 2560px и thumbnail до 800px. Ключи `gallery/<owner UUID>/<image UUID>/{image,thumbnail}.webp` отделены от скинов. Оба объекта записываются и проверяются чтением до SQL-транзакции, которая проверяет активного владельца и создаёт публичную запись. Ошибка S3 возвращает 503 и не создаёт запись снимка.

Изображения выдаются контролируемыми `GET /api/v1/public/gallery/{id}/{image,thumbnail}`, которые проверяют публичную доступность перед чтением private S3. Возвращаются WebP и revalidation caching; ошибки хранилища возвращают 503. `DELETE /api/v1/account/gallery/{id}` проверяет владельца и выполняет soft removal. Будущая очистка private objects может удалять неиспользуемые/удалённые blobs; удалённый снимок недоступен через API. Бакет не становится публичным.

Vega `/gallery` и `/gallery/:id` — публичные SSR-страницы с canonical metadata, semantic tiles, alt и реальными подписями/авторами/датами. Pagination использует обычные ссылки и работает без JavaScript. Ошибки имеют честное unavailable-состояние; неизвестные ID возвращают 404. `/app/gallery/new` использует существующую CSR-аутентификацию аккаунта и поддерживает preview, название, alt, описание, место, optional координаты и отметку присутствия автора на снимке. Object URLs освобождаются. Controls удаления загружаются после hydration и не добавляют защищённые данные аккаунта в public loaders. Public loaders не передают session cookies; service worker не кеширует gallery API или защищённые формы.

`bun run generate` экспортирует OpenAPI и обновляет Alhena; generated files не редактируются вручную. Проверки включают decoder/unit tests, SSR/component tests, `bunx --bun playwright test --config playwright.gallery.config.ts` с локальными gallery fixtures и настоящий lifecycle `bun run --cwd apps/antares test:integration -- tests/gallery.integration.test.ts`. Корневой Playwright дополнительно проверяет авторизованную загрузку/detail/удаление на временных PostgreSQL/S3. Для persistence tests и root E2E нужен Docker daemon; локальные smoke fixtures не подтверждают DB/S3-интеграцию.

Защищённый `GET /api/v1/account/gallery/players?query=…` ищет активных игроков по буквальному префиксу ника без учёта регистра (2–16 символов ника, до 10 результатов). Ответ содержит только UUID и ник и использует `Cache-Control: no-store`. Вега хранит UUID выбранных игроков, показывает головы, исключает повторы и позволяет добавить до 20 участников при загрузке и редактировании подписей. На странице загрузки нет навигации аккаунта. Формы подписей и редакционных переводов показывают один язык за раз и сохраняют остальные значения при переключении и отправке.
