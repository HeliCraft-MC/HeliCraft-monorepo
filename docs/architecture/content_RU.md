# Editorial content

PAGE и CHRONICLE используют общие таблицы с отдельными API-коллекциями. DTO проверяют slug, заголовки, Markdown, SEO, категорию и featured. Новый документ DRAFT; публичные запросы видят только PUBLISHED. Есть снятие с публикации и ARCHIVED. Права read/write/publish проверяются на сервере.

Markdown проходит GFM, безопасные heading ID и rehype-sanitize; raw HTML выключен. Клиент не передаёт готовый HTML. Атрия отображает только очищенный серверный результат. Каждое сохранение добавляет неизменяемую редакцию и аудит; восстановление создаёт новую редакцию. Старые опубликованные slug сохраняются как redirect и не переиспользуются чужими документами. Featured-переходы сериализованы и сохраняют свидетельства изменений вытесненной истории.

Редактор поддерживает предпросмотр, защиту несохранённых изменений, публикацию/снятие/архив и восстановление. Летопись имеет пагинацию и честное пустое состояние. Rules/start могут использовать опубликованную CMS-страницу. Media manager, page builder, расписание и согласование публикаций не реализованы.
