# Identity and sessions

Антарес выдаёт UUID v4 при регистрации; PostgreSQL запрещает его изменение. Ник — отображаемое имя, уникальное без учёта регистра, из 3–16 ASCII-букв, цифр и _. Смена ника требует текущий пароль, сохраняет UUID и атомарно записывает историю и аудит. Пароли хранятся отдельно как Argon2id: 64 МиБ, три итерации; длина нового пароля 12–128 символов.

Регистрация атомарно создаёт ACTIVE-пользователя, PLAYER, credential и сессию. Токен — 32 случайных байта, в БД хранится только SHA-256. Срок сессии: 14 дней простоя, максимум 30 дней; права и статус читаются из БД при каждом запросе. Cookies HttpOnly/SameSite=Lax/Path=/; HTTPS требует Secure и имя __Host-helicraft. Небезопасные запросы проверяют точный Origin и Fetch Metadata, API имеет no-store.

Есть список сессий, отзыв одной/всех, смена пароля с отзывом всех сессий и повторным входом. Бан/приостановка блокируют вход. Rate limits регистрации и входа ограничены одним процессом; для нескольких экземпляров нужен общий store. Email/OAuth и автоматическое восстановление отсутствуют. Ригель сохраняет стандартную аутентификацию до отдельной проверенной интеграции.
