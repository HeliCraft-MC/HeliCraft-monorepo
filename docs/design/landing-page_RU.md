# Landing page design

Публичная `/` — editorial-интерфейс постоянного мира, создаваемого игроками. Композиция остаётся в Vega: фотографический hero, тонкая строка состояния, принципы территории/государственности/экономики/истории из GDD, до трёх реальных одобренных государств, схематичный атлас, экономический preview и финальное приглашение на фотографии. Onest и IBM Plex Mono поставляются локально. Atria предоставляет нейтральные тёплые токены, доступные controls, StateCard, GalleryTile и PhotoCarousel. Primary используется для действий и небольших акцентов.

Названия, описания, флаги, число граждан и общее число государств приходят из опубликованных редакций ACTIVE-государств через Antares/Alhena без session cookies. Пустой каталог отличается от недоступного API. Компании и валюты остаются явно подписанными демонстрационными примерами. Атлас — схематичный placeholder, не карта территорий. PRELAUNCH остаётся состоянием по умолчанию; адрес Minecraft показывается только при OPEN и настроенном адресе. Онлайн не выдумывается. GDD описывает будущие игровые системы, а не выпущенные возможности.

Hero запрашивает одну страницу максимум из шести публичных записей галереи и общее количество без cookies сессии. При количестве больше пяти используются снимки галереи с реальными подписями, авторами, описаниями/местами и ссылками на detail. Иначе, а также при ошибке API, используются локальные архивные снимки с нейтральной атрибуцией. Ошибка загрузки самого изображения также заменяет снимок и подпись архивным fallback. Первый выбор детерминирован при SSR; crossfade запускается после hydration, с интервалом 12 секунд, приостанавливается в скрытой вкладке и учитывает reduced motion. Доступны остановка и переход вперёд. Следующее изображение загружается заранее; слои фотографий имеют фиксированную геометрию. Источник финальной фотографии отличается от активного hero.

Sticky-header интегрирован в hero и становится непрозрачной нейтральной поверхностью после скролла. На mobile есть подписанная кнопка, expanded state и закрытие по Escape. Сохранены мир/хроника/начало/правила, аккаунт, настроенные community и опубликованные legal/CMS ссылки; добавлены настоящий каталог `/states`, галерея и архивная GitHub-организация. Неработающий route будущей карты не создаётся. Публичный HTML содержит контент, подписи фотографий, навигацию и SEO до JavaScript. Загрузка защищена существующей CSR-зоной аккаунта.

## Archive assets

Файлы перенесены из `archive/apps/vesper/public` в активные `apps/vega/public/world`; production не импортирует archive:

| Активный asset | Архивный источник                            |
| -------------- | -------------------------------------------- |
| `logo.png`     | `logo_noback.png`                            |
| `skyline.webp` | `introImg/photo_2025-05-22_19-05-22.jpg`     |
| `town.webp`    | `introImg/photo_2025-05-20_16-45-41.jpg`     |
| `night.webp`   | `introImg/photo_2023-09-14_21-11-51.jpg`     |
| `forest.webp`  | `introImg/photo_2025-05-21_19-37-34 (2).jpg` |
| `castle.webp`  | `introImg/photo_2025-04-20_23-31-07.jpg`     |

Каждый снимок имеет вариант `-small.webp` шириной 800px и display-вариант до 2560px. Подтверждённых подписей не найдено, поэтому используется «Скриншот игроков HeliCraft / Из архива сообщества». Карточки государств показывают настоящие структурированные баннеры игроков или загруженные PNG-флаги.

См. [хранилище и API галереи](../architecture/gallery_RU.md). Browser smoke использует исключительно тестовые gallery fixtures и проверяет SSR, порог количества, fallback при ошибке, 404, hydration и ширины 360–1440px. Отдельный lifecycle загрузки использует настоящие временные PostgreSQL/S3.
