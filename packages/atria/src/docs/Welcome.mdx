## Before composing a screen

1. Choose the persistent workspace and its current navigation item.
2. Group related fields in a typed Form with one language selector.
3. Give the screen one clear next action and a review before publication.
4. Check the narrow screen, keyboard, errors and empty state.

See **Design principles** for interaction decisions and **Contributing** for maintenance rules.
