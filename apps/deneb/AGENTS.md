# Deneb agent guide

- Paper owns physical world facts. Antares owns accounts, immutable UUIDs, admission, citizenship, Governance and finance. Deneb receives the verified profile through Velocity modern forwarding; never invent identity or implement login/register/link.
- Read [Minecraft architecture](../../docs/architecture/minecraft-integration.md) and [development guide](../../docs/development/minecraft-plugins.md). Keep backend ports private and forwarding secrets outside Git. Admission must be checked before playerdata/gameplay.
- Use only scoped `DENEB_SERVICE_TOKEN` and the shared Java REST client. Never access PostgreSQL/S3, use browser cookies or grant administrator API access. Network I/O must be asynchronous with timeout; the explicitly async pre-login event may await a bounded request. Marshal player/Bukkit work to the main thread; capture immutable identity before HTTP callbacks.
- `/heli`, `/heli status`, `/heli profile` use verified Antares data and configured server identity. Show every active citizenship or a neutral value; citizenship is not physical location. Respect locale → English → supported locales for localized domain names. Do not hardcode display branding.
- Join attests actual Paper presence. Quit closes the exact session ID idempotently; heartbeats require current admission and browser approval session. API failure/expiry must terminate admission. Cache only verified data, with bounded lifetime and invalidation. Never send HTTP per tick, movement or block event.
- Keep domain logic independent of Paper. Spatial decisions use local verified JTS snapshots, while Antares/PostGIS owns territorial truth. Plugin-specific physical/cache state cannot grant state offices, financial powers, balances or tax authority. State jurisdiction is independent of citizenship and does not grant claims, block protection or financial authority.
- Root commands: `bun run build:deneb`, `bun run test:deneb`, `bun run lint:java`, `bun run format:check:java`; common client: `./gradlew :minecraft-client:build`. `dev:deneb` rebuilds without reload; restart Paper after replacing the JAR.
- Isolated staging: `bun run minecraft:up`; logs `bun run minecraft:logs deneb`; stop `minecraft:down`; delete only disposable data with `minecraft:clean`. Test EULA is automatically accepted under explicit owner authorization. Never change user worlds or reset user databases.
- Required: JUnit profile/localization/client tests, `bun run test:minecraft:contracts`, real startup and protocol flow via `bun run test:minecraft`. Test wrong UUID, missing/invalid service credentials, direct Paper connection, forwarding mismatch, API outage, quit/crash expiry and reconnect. Native-client acceptance is separate from translated protocol coverage.
- Diagnose exact Paper/Java/plugin versions, `Deneb ready:`, modern forwarding configuration, API origin/token and `Deneb joined account <UUID>`. Report unavailable Docker/browser/Java distinctly. Never print secrets or full HTTP bodies in logs.

- Target native Paper 26.3 with the exact API/server lock. Squaremap is a separately pinned renderer; it never owns legal territory. Keep live-player tracking off by default and its HTTP/backend ports private.
- SpatialEngine verifies world UUID/dimension, schema/version, bounded payload, integrity and JTS validity before building an immutable STRtree and atomically replacing a whole world snapshot. Retain the last verified snapshot on spatial API failure, label stale data, and reconcile without a plugin restart. Authentication still fails closed under its own leases.
- Movement, teleports, world changes and periodic stationary checks use only local geometry on the main thread. No HTTP/PostGIS or index building in the movement path; asynchronous callbacks must not touch Player/Bukkit objects. Exact exterior/hole edges are Wilderness.
- Territory changes require shared PostGIS/JTS boundary fixtures and native runtime tests for actual movement, dwell/jitter, `/heli whereami`, stationary R1→R2 updates and outage/recovery. A contains-only test or successful JAR build is insufficient.
