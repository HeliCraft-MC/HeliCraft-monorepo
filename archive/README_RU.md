# Архив HeliCraft

Старые приложения перенесены без сброса локальных изменений:

- [Vesper](apps/vesper/README.md) — Nuxt/Vue.
- [Teapot](apps/teapot/README.md) — Nitro/Bun, MySQL/SQLite.
- [Soon](apps/soon/README.md) — самостоятельная coming-soon страница.

Исходный корневой README сохранён в [README.md](README.md), документация — в [docs](docs), прежние инструкции — в [AGENTS.md](AGENTS.md). Локальные env-файлы, зависимости и runtime-данные также перемещены, но остаются игнорируемыми Git. Архив не входит в новый workspace, сборки и Docker-контекст. Старые API и данные автоматически не переносятся.
