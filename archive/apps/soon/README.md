# HeliCraft Coming Soon

Небольшая автономная Node.js-страница-заглушка в стиле сайта HeliCraft. Заголовки используют Press Start 2P через Google Fonts, фон по очереди показывает локальные копии скриншотов главной страницы Vesper. Внешние зависимости npm не нужны.

Шрифт загружается из Google Fonts. Если Google Fonts недоступен в браузере, заголовки используют моноширинный пиксельный запасной шрифт. Скриншоты лежат в `public/screenshots` и не требуют обращения к Vesper во время сборки или работы приложения.

## Запуск через Docker Compose

Из каталога `apps/soon`:

```bash
docker compose up --build -d
```

Страница будет доступна на http://localhost:3080. Порт можно изменить переменной `SOON_PORT`, например:

```bash
SOON_PORT=3081 docker compose up --build -d
```

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm start
```

Приложение слушает `0.0.0.0:3000` по умолчанию. Переменные `HOST` и `PORT` можно переопределить. Проверка готовности доступна по `/healthz`.

## Остановка и очистка

```bash
docker compose down --rmi local --remove-orphans
```

Команда удаляет контейнеры и собранный локальный образ этого приложения.
